# Hotel Website — Claude Code Instructions

## Project context
This is a hotel website previously generated by Codex. 
The goal is a COMPLETE redesign — new visual identity, 
new component structure, new UX patterns. Preserve only 
the core content (room names, amenities, pricing, copy).
Do NOT preserve any existing styles, class names, or 
layout patterns unless explicitly asked.

## Hotel identity
- Name: [YOUR HOTEL NAME]
- Location: [CITY, COUNTRY]
- Vibe: [e.g. boutique luxury / cosy mountain retreat / 
         beachfront modern / heritage colonial]
- Target guest: [e.g. couples, business travellers, families]
- Key differentiator: [e.g. rooftop infinity pool, 
  forest views, central location, farm-to-table dining]

## Design direction
- Aesthetic: refined editorial luxury (think Condé Nast 
  Traveller layout meets boutique brand identity)
- Color palette: derive from hotel vibe — do NOT use 
  generic blue/purple gradients or white-on-white cards
- Typography: choose a distinctive display font (e.g. 
  Playfair Display, Cormorant, Canela) paired with a 
  clean sans for body
- Photography: use high-quality Unsplash placeholder 
  images relevant to the property type
- Animations: subtle scroll reveals, parallax hero, 
  smooth hover states — no flashy transitions

## Tech stack
- Keep whatever framework Codex used UNLESS it makes 
  the redesign harder, in which case migrate to plain 
  HTML/CSS/JS or Next.js (your call)
- Use CSS custom properties for all theme tokens
- Mobile-first, fully responsive

## Pages to redesign
1. Home / Landing
2. Rooms & Suites
3. Dining
4. Experiences / Activities
5. Contact & Reservations

## What to audit first
Before writing a single line of new code, read ALL 
existing files and produce a short audit:
- What content exists (keep this)
- What structure/styles exist (replace all of this)
- Any broken or low-quality patterns to flag

## Code standards
- Semantic HTML (use article, section, header, nav, main)
- Accessible (aria-labels, alt text, focus states)
- No inline styles except for dynamic JS values
- CSS variables for every color, font, spacing token
- Components in separate files if using a framework

## Do not
- Do not use Bootstrap, Tailwind, or any utility framework
- Do not copy Codex's class naming conventions
- Do not ask for permission before making design decisions
- Do not produce placeholder "to be styled" sections
